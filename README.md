# journeyfy-links

The web pages of the [Journeyfy](https://github.com/FranDesarrolladorWeb/Journeyfy) apps for iPhone
and Android, published with GitHub Pages at https://frandesarrolladorweb.github.io/journeyfy-links/.

- `join/` — invite links (`/join/?token=…`). Messengers only auto-link `https://` URLs, so invites
  point here, and the page opens the `journeyfy://join?token=…` deep link in the app (on Android
  through an `intent://` link that falls back to Google Play).
- `privacy/` — the privacy policy.

The pages' sources live in the Journeyfy repo, under `docs/links-site/`; edit them there and copy
them here.
